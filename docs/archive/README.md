# Archived planning documents

The files in this directory are superseded planning inputs retained for
traceability. They are not current implementation, security, privacy or
deployment authority.

Use the repository-root `ENTERPRISE_PRODUCT_MASTER_PLAN.md`, accepted ADRs,
approved specifications and `docs/STATUS.md` for current decisions. Do not
restore an archived requirement into implementation without reconciling it
through the repository's decision process.
