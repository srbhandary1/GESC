## Bounded interpretation

The line break between `production/` and `public release` is preserved exactly
as supplied and is interpreted only as **production/public release remains
prohibited**. It does not create a release exception.

For the four exact hashes above, this authorization permits:

- copying the owner-designated upstream teaching media into the project's
  private non-production quarantine and accepted-media storage;
- inspection, malware scanning and accessibility processing;
- transcription and bounded AI-assisted derivative lesson drafting only
  through project-owned adapters under existing no-training, minimum-retention,
  spend and kill-switch controls; and
- eventual web/Android learner delivery in India only after current content,
  rights, English academic, Kannada and publication gates pass.

It prohibits:

- cross-tenant or public sharing, cloning or public URLs;
- production/public release;
- automatic academic, Kannada, answer-key or publication approval;
- treating provider output as marks, mastery, unlock or authoritative content;
- use of unselected legacy Assignment audio or any learner-originated media;
  and
- bypassing exact hash, inspection, clean-scan, appointment, attachment,
  immutable-publication, privacy or retention controls.

The authorization is effective for this bounded non-production LPL-01 work
until superseded or revoked by an append-only owner decision. Existing
published evidence, if any is later created, remains immutable and requires a
successor publication for changed rights.
