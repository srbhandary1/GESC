# Phase 1 Audio Lessons drop-in

Put **licensed** per-level masters here. The demo prefers these files over
the authenticated studio stream and over scripted TTS. Do not commit
unlicensed media.

See [docs/PHASE1_LEVEL_AUDIO.md](../../../../../../docs/PHASE1_LEVEL_AUDIO.md)
for the naming contract and coverage table.

## Filenames

| Level | Drop this file |
|---|---|
| Pre-1 | `pre-1.mp3` (or `.wav` / `.m4a` / `.ogg` / `.webm`) |
| Pre-2 | `pre-2.mp3` |
| Level 1 | `level-1.mp3` |
| … | … |
| Level 17 | `level-17.mp3` |

Optional: set `"file"` on that level in `manifest.json` if you use another
filename. Daily Activity is a **different** one-audio/day clip — do not
reuse it here.
