# Global Spoken English App – Complete Brand Kit

Professional logo & identity system for an AI-powered spoken English learning app.

## Contents

### Logos/
- `logo-primary-horizontal.svg` – Main logo for websites & headers
- `logo-stacked.svg` – Vertical version for square layouts
- `logo-icon-only.svg` – Symbol only (globe + e)
- `logo-white-version.svg` – For dark backgrounds
- `logo-dark-version.svg` – High-contrast dark mode version

### Favicon/
- `favicon.svg` – Modern SVG favicon (also convert to .ico / PNG sizes)

### App-Icons/
- `app-icon.svg` – Full 1024-style app icon with rounded background

### Guidelines/
- `brand-guidelines.txt` – Colors, usage rules, taglines

## How to use

1. SVGs are resolution-independent – open in any browser, Figma, Illustrator, or Inkscape.
2. For PNG/JPG exports (app stores, social media, etc.) use:
   - https://svgtopng.com
   - Figma / Illustrator export
   - Or any vector editor
3. Recommended export sizes are listed in the guidelines file.

## Color reference
- Green: #006B3F / #00A86B
- Red: #E31C23
- Text: #1A1A2E

Enjoy building the app!
