# Client deliverables

This directory preserves the client-facing planning package prepared on
29 July 2026, including its editable source and generated DOCX/PDF artefacts.
The top-level ZIP contains byte-identical copies of the two files in
`deliverables/final/`.

These documents are historical commercial/planning artefacts. They are not
the current implementation or deployment authority. When they conflict with
the repository baseline, use `ENTERPRISE_PRODUCT_MASTER_PLAN.md`, accepted
ADRs, approved specifications and `docs/STATUS.md` in that order.

Do not place credentials, environment files, learner data, provider evidence
or deployment secrets in this directory or its generated packages.
